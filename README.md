# 🏥 Healthcare Leads Flow Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **Healthcare Leads Flow Dashboard** developed using **Microsoft Power BI**.

The dashboard provides an overview of hospital and patient-related information, including admission and discharge dates, diagnosis types, medical tests, bed occupancy, billing amounts, health insurance amounts, and doctor feedback.

The purpose of the dashboard is to transform healthcare data into clear and interactive visual insights for easier monitoring and analysis.

---

## 🎯 Project Objectives

- Monitor patient admission, discharge, and follow-up information
- Analyze the distribution of different diagnoses
- Track medical tests performed
- Analyze bed occupancy across wards and diagnoses
- Compare billing amounts with health insurance amounts
- Review doctor feedback volume
- Allow patient-specific analysis using interactive filters

---

## 📊 Dashboard Features

### 📅 Patient Timeline

Displays important patient dates including:

- Admitted Date
- Discharge Date
- Follow-Up Date

A date range filter is also available for analyzing records within a selected period.

### 🩺 Diagnosis Type

Displays the distribution of patients across different diagnoses, including:

- Viral Infection
- Flu
- Malaria
- Typhoid
- Pneumonia
- Fracture

### 🧪 Test Type Analysis

Shows the number of different medical tests performed, including:

- Blood Test
- MRI
- CT Scan
- Ultrasound
- X-Ray

### 🛏️ Bed Occupancy by Wards

Analyzes bed occupancy across:

- Private
- General
- ICU

### 📊 Bed Occupancy by Diagnosis

Compares bed occupancy across different diagnosis categories.

### 💰 Billing vs Health Insurance

Compares the **Billing Amount** with the **Health Insurance Amount** for different diagnosis categories.

This visualization helps identify differences between healthcare costs and insurance coverage.

### 👨‍⚕️ Doctor Feedback Volume

Displays the distribution of feedback associated with different doctors.

### 🔎 Patient Filter

The **Patient ID** filter allows users to view information for individual patients.
